# FRICTION.md — the only Phase 0 deliverable

Rule: **one line every time logging fails.** A skipped event, a command you reached for
and didn't find, a moment where typing felt like too much. No editing, no prose, no
grouping. This file is the spec for the next phase — features that never show up here
never get built.

Format (date, then what happened):

```
2026-08-31  skipped logging a leetcode problem at 1am - didn't want to open a terminal
2026-08-31  wanted `t week` to see the last 7 days at a glance
```

## Meta-metric

**days-with-at-least-one-event.** Read it off `t stats 30` ("logging: N of 30 days had an
event") or the `days` column in `t stats --weeks 8`. If it drops, fix friction before
building anything else — a decline in the chart must mean a decline in you, not a
decline in your logging.
